# My Fantasy Love

**My Fantasy Love (MFL)** es una aplicación Android de roleplay interactivo asistido por inteligencia artificial.

### ¿Qué puedes hacer en la app?
* Explorar personajes públicos creados por la comunidad y comenzar historias inmersivas.
* Crear tus propios personajes con personalidad, trasfondo, escenario y retratos generados con IA.
* Personalizar el nombre con el que cada personaje se refiere a ti dentro de cada conversación.
* Elegir entre tema visual **Oscuro** y **Claro**, y guardar tu progreso de forma segura en la nube.
